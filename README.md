# Hiddify-SellBot

**نسخه پایدار: `v6.0.4`**

سیستم فروش و مدیریت اشتراک در تلگرام با پشتیبانی از فروش مستقیم، نمایندگی، چند سرور و چند پنل.

## ربات‌های پروژه

- **ربات مدیریت**: کنترل کاربران، سرورها، نودها، پرداخت‌ها، نمایندگان و گزارش‌ها
- **ربات کاربران**: خرید، تمدید، کیف پول، دریافت اشتراک و پشتیبانی
- **ربات نمایندگی**: مدیریت مشتری، سرویس، کیف پول و فروش نماینده
- **ربات مشتری نماینده**: فروش و تمدید مستقل برای مشتریان هر نماینده

## امکانات کاربران

- خرید اشتراک
- تمدید اشتراک
- تست رایگان
- مشاهده مصرف و زمان باقی‌مانده
- دریافت لینک اشتراک، کانفیگ و کد `QR`
- اتصال اشتراک موجود
- کیف پول و شارژ حساب
- کد تخفیف و تخفیف پلکانی
- سیستم دعوت دوستان
- یادآوری پایان حجم و زمان
- تیکت و پشتیبانی
- راهنمای اتصال برای سیستم‌عامل‌های مختلف

## خرید و تمدید

- پلن ثابت و پلن پویا
- انتخاب حجم و مدت
- محاسبه خودکار قیمت
- پرداخت از کیف پول یا روش‌های فعال
- ساخت خودکار سرویس روی سرور اصلی و نودها
- تمدید حجم و زمان
- پشتیبانی از حالت افزایشی یا ریست
- همگام‌سازی تمدید روی نودها
- حفظ شناسه سرویس در ساختار چندسروره

## پرداخت

- کارت‌به‌کارت
- ارسال رسید
- تایید دستی
- تایید خودکار پیامک بانکی
- کیف پول
- پرداخت ارزی و رمزارزی در صورت فعال‌سازی
- جلوگیری از تایید یا شارژ دوباره

- ساخت و تمدید سرویس
- کیف پول نماینده
- قیمت فروش مستقل
- مشاهده سود و هزینه عمده

## نصب سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

یا:

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
sudo ./install.sh install
```

## مدیریت

```bash
sudo ./install.sh panel
sudo ./install.sh status
sudo ./install.sh restart
sudo ./install.sh logs
sudo ./install.sh update
```
