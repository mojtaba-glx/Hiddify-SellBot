# Hiddify-SellBot

**Hiddify-SellBot v6.0.0 Stable** یک سیستم فروش و مدیریت اشتراک VPN در تلگرام است که چهار ربات مستقل را در یک ساختار یکپارچه اجرا می‌کند و از چند خانواده پنل به‌صورت همزمان پشتیبانی می‌کند.

### پنل‌های پشتیبانی‌شده

- **Hiddify Manager** — سازگار با نسخه‌های v11، v12 و v13 با تشخیص نسخه پنل
- **X-UI Sanaei / 3x-ui**
- **X-UI Alireza**
- **X-Net** — اضافه‌شده در نسل v6 با مدیریت سرور، کاربر، نود و Subscription

پروژه شامل ۴ ربات است:

| ربات | نقش |
|---|---|
| **AdminBot** | مدیریت کل سیستم، سرورها، کاربران، نمایندگان، گزارش‌ها و کانال |
| **UserBot** | فروش و مدیریت اشتراک کاربران اصلی |
| **AgentBot** | پنل کامل نمایندگی / Reseller |
| **CustomerBot** | ربات فروش اختصاصی مشتریان هر نماینده |

## 🚀 مهم‌ترین تغییرات v6.0.0

نسخه 6 یک Major Release برای گسترش معماری Multi-Panel و پایدارسازی بخش‌های اصلی پروژه است.

- اضافه‌شدن **X-Net** به‌عنوان پنل مستقل در کنار Hiddify و X-UI
- پشتیبانی همزمان از **Hiddify v11/v12/v13**
- تکمیل احراز هویت X-Net با API Token و JWT fallback
- جداسازی آدرس API داخلی، پنل وب و Subscription عمومی X-Net
- اصلاح لینک‌های کاربر و Subscription در X-Net
- یکسان‌سازی منطق انقضا در Hiddify، Sanaei و Alireza X-UI
- مخفی‌شدن کانفیگ واقعی بعد از انقضا و نمایش فقط کانفیگ وضعیت Trojan
- جلوگیری از نشت کانفیگ واقعی از Smart Subscription بعد از پایان سرویس
- ترمیم mappingهای گمشده نودهای X-UI و retry عملیات disable
- اصلاح حذف/مخفی‌سازی سرویس‌های پاک‌شده از CustomerBot
- همسان‌سازی منطق تمدید UserBot، AgentBot و CustomerBot
- توسعه گزارش‌های مالی و فروش روزانه
- اضافه‌شدن مدیریت ارسال پست کانال برای ادمین و نمایندگان
- رفع مجموعه بزرگی از باگ‌های UserBot، AdminBot، AgentBot، CustomerBot، نودها و Subscription

### 📊 گزارش روزانه

AdminBot دارای گزارش کامل روزانه فروش و عملیات مالی است:

- مجموع دریافتی تاییدشده

- تفکیک تایید خودکار SMS و سایر روش‌ها
- تعداد سرویس‌های ساخته‌شده
- تعداد تمدیدها

- عملیات مستقیم نمایندگان
- تفکیک گردش مالی سرویس از دریافتی بانکی

گزارش روزانه به‌صورت خودکار اجرا می‌شود و امکان مشاهده دستی آن از منوی مدیریت نیز وجود دارد.

## ⚙️ معماری Multi-Panel

### Hiddify

- پشتیبانی از v11، v12 و v13
- تشخیص نسخه پنل
- حفظ سازگاری با API نسخه‌های قدیمی‌تر
- مدیریت کاربر، مصرف، انقضا و Subscription
- fallback برای lookup کاربران در APIهای متفاوت Hiddify

### X-UI

پشتیبانی از:

- Sanaei / 3x-ui
- Alireza X-UI
- چند Inbound
- UUID مشترک سرویس
- جمع مصرف چند Inbound
- عملیات create / renew / enable / disable / delete
- ترمیم mappingهای نود
- retry عملیات انقضا

### X-Net

X-Net در v6 به‌صورت رسمی به Multi-Panel اضافه شده است:

- افزودن سرور اصلی و نود X-Net
- پشتیبانی از Management API Token
- JWT fallback در صورت رد Token
- کش JWT مشترک بین پردازش‌های ربات
- circuit breaker برای جلوگیری از loginهای تکراری و lockup
- آدرس جداگانه API داخلی
- آدرس مستقل پنل وب
- Subscription endpoint عمومی مستقل
- لینک مستقیم صفحه مدیریت Subscription کاربر
- Health Probe سبک برای جلوگیری از اسکن سنگین کاربران

## ⏳ انقضا و امنیت Subscription

منطق انقضا در v6 برای Hiddify، Sanaei و Alireza X-UI یکسان‌سازی شده است.

پس از پایان واقعی سرویس:

- کانفیگ‌های واقعی دیگر از لینک اشتراک برگردانده نمی‌شوند
- Smart Subscription قفل می‌شود
- فقط کانفیگ وضعیت **Trojan** برای نمایش وضعیت انقضا باقی می‌ماند
- نودهای X-UI نیز disable می‌شوند
- اگر disable یک نود تایید نشود، عملیات در چرخه بعد retry می‌شود
- AdminBot می‌تواند نودهای دارای disable pending را گزارش کند

## 🔗 Smart Subscription

هر سرویس می‌تواند یک لینک اختصاصی داشته باشد:

```text
https://your-domain.com/sub/<TOKEN>/all.txt
```

ویژگی‌ها:

- تجمیع کانفیگ‌های سرور اصلی و نودها
- حذف کانفیگ‌های تکراری
- QR داخلی
- خروجی Base64
- اطلاعات حجم و انقضا در Header استاندارد
- ردیف وضعیت مصرف و زمان
- پشتیبانی Multi-Panel
- قفل‌شدن امن لینک بعد از انقضا

## 📥 نصب سریع

روی سرور خام:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

یا با Git:

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
sudo ./install.sh install
```

نصب SSL لینک اشتراک:

```bash
sudo ./install.sh ssl your-domain.com admin@example.com
```
