# Hiddify-SellBot

**Hiddify-SellBot v6.0.4 Stable** یک سیستم کامل فروش، تمدید، مدیریت و پشتیبانی اشتراک VPN در تلگرام است. این پروژه برای مدیریت فروش مستقیم، سیستم نمایندگی، ربات مشتری نمایندگان، چند سرور و چند نوع پنل طراحی شده و چهار ربات مستقل را در یک ساختار یکپارچه اجرا می‌کند.

هدف پروژه این است که بیشتر کارهای روزمره فروش VPN بدون نیاز به ورود مداوم به پنل‌ها انجام شود؛ از خرید و تمدید گرفته تا مدیریت کیف پول، پرداخت، ساخت سرویس، همگام‌سازی نودها، گزارش فروش، مدیریت کاربران، پشتیبانی، کانال و بکاپ.

## پنل‌های پشتیبانی‌شده

- **Hiddify Manager**
  - سازگار با نسخه‌های v11، v12 و v13
  - تشخیص نسخه پنل
  - مدیریت کاربر، مصرف، انقضا، وضعیت آنلاین و Subscription
- **X-UI Sanaei / 3x-ui**
- **X-UI Alireza**
- **X-Net**
  - مدیریت سرور، کاربر، نود و Subscription
  - پشتیبانی از API Token و JWT fallback

## ساختار پروژه

پروژه شامل چهار ربات است:

| ربات | کاربرد |
|---|---|
| **AdminBot** | مدیریت کل سیستم، کاربران، سرورها، نودها، نمایندگان، فروش، گزارش‌ها و تنظیمات |
| **UserBot** | فروش مستقیم به کاربران نهایی، تمدید، کیف پول، دریافت کانفیگ و پشتیبانی |
| **AgentBot** | پنل کامل نمایندگان برای مدیریت مشتری، سرویس، کیف پول و ربات مشتری |
| **CustomerBot** | ربات فروش اختصاصی هر نماینده برای مشتریان همان نماینده |

# 🛒 فروش و خرید اشتراک

سیستم فروش می‌تواند چرخه کامل خرید را داخل تلگرام انجام دهد.

- نمایش پلن‌های قابل فروش
- پشتیبانی از پلن‌های ثابت

- پرداخت از کیف پول
- پرداخت با روش‌های فعال‌شده توسط مدیر

در صورت بروز خطا هنگام ساخت سرویس، سیستم تلاش می‌کند عملیات ناقص را مدیریت کند تا از ایجاد سرویس شبح یا برداشت اشتباه از موجودی جلوگیری شود.

# ⏳ مدیریت انقضا

سیستم انقضای سرویس را فقط در سطح تلگرام بررسی نمی‌کند؛ وضعیت واقعی پنل و نودها نیز در نظر گرفته می‌شود.

پس از پایان سرویس:

- دسترسی کاربر محدود یا غیرفعال می‌شود
- کانفیگ واقعی از Smart Subscription حذف می‌شود
- لینک هوشمند وضعیت انقضا را نمایش می‌دهد
- نودهای مرتبط غیرفعال می‌شوند
- عملیات ناموفق disable دوباره بررسی می‌شود
- سرویس منقضی با فعال‌سازی ساده دوباره قابل استفاده نیست
- برای شروع دوره جدید باید تمدید انجام شود

# 📥 نصب سریع

روی سرور خام:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

یا با Git:

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
sudo ./install.sh install
```

نصب SSL لینک اشتراک:

```bash
sudo ./install.sh ssl your-domain.com admin@example.com
```

```bash
cd ~/Hiddify-SellBot

sudo ./install.sh logs
sudo ./install.sh update
sudo ./install.sh stop
sudo ./install.sh uninstall
```

اجرای دستی:

```bash
python -m AdminBot.main
python -m UserBot.main
python -m AgentBot.main
python -m CustomerBot.main
```
