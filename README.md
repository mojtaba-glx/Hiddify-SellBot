# Hiddify-SellBot

Hiddify-SellBot یک ربات فروش و مدیریت اشتراک Hiddify برای تلگرام است. پروژه شامل چهار ربات جداگانه است:

- **AdminBot** برای مدیریت سرورها، کاربران، پلن‌ها، پرداخت‌ها و تنظیمات
- **UserBot** برای خرید اشتراک، تمدید، مشاهده سرویس، کیف پول، تیکت و دریافت کانفیگ
- **AgentBot** پنل نمایندگی (Reseller) — نماینده‌ها مشتریان خودشون رو مدیریت می‌کنن
- **CustomerBot** ربات مشتری نماینده — هر نماینده یک ربات اختصاصی برای مشتریانش داره

تمرکز پروژه روی فروش اشتراک، مدیریت چندسروره، نودسازی، لینک اشتراک اختصاصی و ساده‌سازی نصب/آپدیت روی سرور است.

## نصب سریع روی سرور خام

اگر سرور تازه است و حتی `git` نصب نیست، این دستور کافی است:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

اجرای مستقیم فرمان‌ها با bootstrap:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh) install
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh) update
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh) panel
```

## نصب با Git

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
./install.sh
```

برای باز کردن منوی مدیریت روی سرور:

```bash
cd ~/Hiddify-SellBot
sudo ./install.sh panel
```

## منوی مدیریت نصب

```text
1) install
2) update (safe)
3) update-force (hard sync)
4) restart
5) status
6) autostart manager
7) ssl setup wizard
8) hiddify user stabilizer
9) help
0) exit
```

برای آپدیت عادی همیشه گزینه `update (safe)` پیشنهاد می‌شود. این گزینه قبل از آپدیت بکاپ می‌گیرد و داده‌های runtime مثل دیتابیس، سرورها، پلن‌ها، لاگ‌ها و بکاپ‌ها را حذف نمی‌کند.

## قابلیت‌های UserBot

- ثبت و مدیریت کاربران تلگرام
- نمایش منوی خرید، تمدید، کیف پول، سرویس‌ها و پشتیبانی
- خرید اشتراک از روی پلن‌های ثابت یا پویا
- تمدید اشتراک با سیاست‌های قابل تنظیم برای حجم و زمان
- نمایش وضعیت اشتراک شامل نام، سرور، حجم مصرفی، حجم کل، زمان باقی‌مانده، قیمت و شناسه
- دریافت کانفیگ مستقیم، لینک اشتراک، لینک b64 و لینک اشتراک هوشمند
- پشتیبانی از تست رایگان با حجم اعشاری مثل `0.2`، `0.5` و `0.75` گیگ
- کیف پول کاربر، شارژ کیف پول و پرداخت از موجودی
- پرداخت کارت‌به‌کارت همراه با رسید
- پشتیبانی از لینک‌های زرین‌پال/ووچر در صورت فعال‌سازی
- سیستم تیکت پشتیبانی بین کاربر و ادمین
- یادآوری نزدیک شدن پایان زمان یا حجم هر اشتراک
- اتصال اشتراک موجود با UUID یا لینک کانفیگ
- نمایش دکمه‌های قابل تنظیم برای خرید، تمدید، تست رایگان، لینک‌ها و پشتیبانی
- پشتیبانی از دکمه‌های رنگی تلگرام برای تجربه کاربری زیباتر و واضح‌تر

- ساخت کاربر روی Hiddify و نودهای مرتبط
- افزودن کاربر دستی، افزودن کاربر با پلن و افزودن چندین کاربر همزمان
- جستجوی کاربران با شناسه عددی، نام کاربری و اطلاعات سرویس
- تغییر نام، حجم، زمان، وضعیت و حذف سرویس کاربران
- حذف گروهی کاربران منقضی‌شده
- مدیریت پلن‌های ثابت، دسته‌بندی پلن‌ها و پلن پویا
- تنظیم قیمت هر گیگ، قیمت زمان، بازه حجم/زمان و تخفیف حجمی
- مدیریت تنظیمات خرید و تمدید
- مدیریت کارت‌های بانکی و روش‌های پرداخت
- تایید، رد و بررسی پرداخت‌ها
- مدیریت کیف پول کاربران و تراکنش‌ها
- مدیریت پیام‌ها و متن‌های قابل نمایش در ربات کاربران
- مدیریت ظاهر دکمه‌های رنگی با امکان خاموش/روشن و انتخاب طرح
- مدیریت تیکت‌های کاربران
- گزارش فروش، سفارش‌ها، تراکنش‌ها و وضعیت کاربران
- دستور `/debug` برای گزارش وضعیت ربات، فایل‌ها، دیتابیس، jobها، شبکه و لاگ‌ها

- مدیریت سیستم نمایندگی (AgentBot/Reseller):
  - افزودن/حذف/فعال/غیرفعال کردن نماینده‌ها
  - شارژ کیف پول نماینده
  - تعیین قیمت عمده (wholesale) برای هر پلن/سرور
  - مشاهده آمار کلی سیستم نمایندگی

## قابلیت‌های AgentBot (پنل نماینده)

- داشبورد با آمار فروش، سود و موجودی کیف پول
- مدیریت مشتریان (افزودن/حذف/مشاهده)
- ساخت سرویس مستقیم از پنل Hiddify (با کسر هزینه عمده از کیف پول)
- تمدید، فعال/غیرفعال و حذف سرویس
- دریافت کانفیگ‌های هر سرویس از پنل Hiddify
- تعیین قیمت فروش برای هر پلن (باید ≥ قیمت عمده)
- مشاهده تراکنش‌های کیف پول
- ثبت ربات مشتری اختصاصی (CustomerBot) — محدودیت ۱ ربات به ازای هر نماینده
- گزارش فروش و سود

## قابلیت‌های CustomerBot (ربات مشتری نماینده)

- ثبت‌نام خودکار مشتریان در سیستم نماینده
- خرید اشتراک از پلن‌های نماینده (با کسر هزینه عمده از کیف پول نماینده)
- مشاهده سرویس‌ها و وضعیت مصرف (همگام‌سازی از پنل Hiddify)
- دریافت کانفیگ‌های اتصال (VLESS/VMESS/Trojan)
- تمدید سرویس
- ارسال پیام پشتیبانی به نماینده
- Multi-Bot Runner: تمام ربات‌های مشتری فعال همزمان اجرا می‌شوند
- Hot-reload: افزودن/حذف ربات بدون نیاز به ریستارت

## دکمه‌های رنگی تلگرام

از بخش `⚙️تنظیمات ربات کاربران` می‌توانید وارد `🎨 دکمه‌های رنگی` شوید و ظاهر دکمه‌ها را مدیریت کنید.

- روشن/خاموش کردن کامل رنگی بودن دکمه‌ها
- طرح `✨ هوشمند`: رنگ‌بندی متعادل برای تأیید، خرید، حذف، بازگشت و تنظیمات
- طرح `🛒 فروشگاهی`: تأکید بیشتر روی خرید، تمدید، کیف پول، پرداخت و کوپن‌ها
- طرح `💼 حرفه‌ای`: ظاهر آرام‌تر برای پنل‌های مدیریتی
- طرح `🕊 مینیمال`: فقط اکشن‌های خیلی مهم رنگی می‌شوند

این قابلیت فقط ظاهر دکمه‌ها را تغییر می‌دهد و روی عملکرد خرید، پرداخت، تمدید یا مدیریت کاربران اثری ندارد.

## لینک اشتراک هوشمند

ربات می‌تواند برای هر سرویس یک لینک اشتراک هوشمند اختصاصی بسازد:

```text
https://your-domain.com/sub/<USER_UUID>/all.txt
```

این لینک:

- با UUID اختصاصی همان کاربر ساخته می‌شود
- کانفیگ‌های همه سرورها و نودهای فعال را تجمیع می‌کند
- نام پروفایل را از نام اشتراک به برنامه کلاینت ارسال می‌کند
- حجم مصرفی را از همه نودهای همان سرویس جمع می‌زند
- حجم کل و زمان باقی‌مانده را در هدر استاندارد `subscription-userinfo` ارسال می‌کند
- لینک را همراه با بارکد QR داخلی و بدون وابستگی به سرویس خارجی تحویل می‌دهد
- با بروزرسانی پروفایل داخل برنامه، دوباره از سرورها اطلاعات تازه می‌گیرد
- مسیر قدیمی توکن‌دار را برای سازگاری نگه می‌دارد

نمونه:

```text
https://sell.example.com/sub/170e48be-4cbd-4e6e-ae93-a58b8ba16609/all.txt
```

## SSL برای لینک‌های اشتراک هوشمند

اگر ربات روی سرور جدا نصب شده باشد، ساده‌ترین روش:

```bash
cd ~/Hiddify-SellBot
sudo ./install.sh ssl sell.example.com admin@example.com
```

این دستور `nginx` و `certbot` را نصب می‌کند، گواهی Let's Encrypt می‌گیرد و ترافیک HTTPS دامنه را به سرویس داخلی ربات وصل می‌کند.

اگر ربات کنار پنل Hiddify روی همان سرور نصب شده است، قبل از اجرای SSL باید با دقت reverse proxy تنظیم شود تا با HAProxy/Nginx پنل تداخل ایجاد نشود. در این حالت معمولاً بهتر است ربات روی سرور جداگانه نصب شود یا مسیر proxy موجود پنل به شکل کنترل‌شده تنظیم شود.

## اپ Android تایید SMS کارت‌به‌کارت

پوشه `SmsVerifierAndroid` شامل اپ اندروید ساده برای دریافت SMSهای بانکی و ارسال امن گزارش به Webhook ربات است.

- فیلتر سرشماره بانک برای جلوگیری از ارسال SMSهای نامرتبط
- فیلتر اختیاری چهار رقم آخر کارت با امکان روشن/خاموش
- استخراج مبلغ، واحد پول و شماره پیگیری از SMS
- ارسال Payload با Secret Key به endpoint ربات
- تبدیل خودکار مبلغ ریالی SMS بانک به تومان برای تطبیق با پرداخت‌های ربات
- نگهداری گزارش SMSهای ارسال‌شده، ردشده یا خطاخورده داخل اپ

Webhook پیش‌فرض:

```text
https://YOUR_SUB_DOMAIN/payment/sms-webhook
```

تنظیمات سمت ربات:

```env
SMS_WEBHOOK_ENABLED=true
SMS_WEBHOOK_SECRET=یک_رمز_طولانی_و_تصادفی
SMS_WEBHOOK_MAX_PENDING_AGE_MINUTES=360
```

راهنمای ساخت APK و اتصال در `SmsVerifierAndroid/README.md` قرار دارد.

## Hiddify User Stabilizer

برای بعضی نسخه‌های پنل Hiddify ممکن است کاربر تازه‌ساخته‌شده بعد از چند دقیقه قطع شود. این بخش یک فیکس موقت قابل خاموش/روشن دارد:

```bash
./install.sh stabilizer
```

حالت‌ها:

- `toggle`: ساخت کاربر، ذخیره مجدد، غیرفعال‌سازی کوتاه و فعال‌سازی دوباره؛ حالت پیشنهادی
- `update`: فقط ذخیره/آپدیت دوباره بعد از ساخت
- `off`: خاموش کردن کامل فیکس موقت

## بکاپ و داده‌ها

- دیتابیس اصلی در `Shared/hiddify_sellbot.db` نگهداری می‌شود.
- فایل‌های سرورها و پلن‌ها در `Shared/servers.json` و `Shared/plans.json` هستند.
- بکاپ‌ها داخل پوشه `backups` ذخیره می‌شوند.
- آپدیت امن، داده‌های runtime را حذف نمی‌کند.
- قبل از تغییرات مهم، از داخل ربات یا از پوشه پروژه بکاپ بگیرید.

## نکات امنیتی

- فایل `.env` شامل توکن‌ها و اطلاعات حساس است و نباید در GitHub قرار بگیرد.
- برای `ADMIN_BOT_TOKEN` و `USER_BOT_TOKEN` باید دو ربات جدا از BotFather ساخته شود.
- برای سیستم نمایندگی: `AGENT_BOT_TOKEN` ربات نمایندگی و هر نماینده توکن CustomerBot خودش را ثبت می‌کند.
- اگر دو سرور با یک توکن تلگرام همزمان روشن شوند، Telegram خطای `Conflict` می‌دهد.
- دسترسی SSH سرور را امن نگه دارید و از ارسال پسورد یا private key در چت خودداری کنید.

## اجرای ربات‌ها

```bash
# روش ۱: اسکریپت جامع (همه ربات‌ها)
./run_bots.sh start      # شروع همه ربات‌ها
./run_bots.sh stop       # توقف همه ربات‌ها
./run_bots.sh restart    # ریستارت
./run_bots.sh status     # وضعیت
./run_bots.sh logs adminbot   # مشاهده لاگ

# روش ۲: اجرای دستی هر ربات
python -m AdminBot.main          # ربات ادمین
python -m UserBot.main           # ربات کاربران
python -m AgentBot.main          # ربات نمایندگی
python -m CustomerBot.main       # Runner ربات‌های مشتری (همه ربات‌های فعال)
```
