# Hiddify-SellBot

**فروشگاه و پنل مدیریت کامل اشتراک در تلگرام — از خرید تا تمدید، نمایندگی و مدیریت چند سرور**

**نسخه پایدار: `v6.0.16`**

فقط یک ربات فروش نیست؛ یک سیستم کامل برای مدیریت کسب‌وکار اشتراک است. کاربر خرید می‌کند، پرداخت انجام می‌دهد، سرویس به‌صورت خودکار ساخته می‌شود، لینک اشتراک تحویل می‌گیرد و بعداً همان سرویس را تمدید می‌کند؛ در سمت مدیریت هم کاربران، سرورها، نودها، نمایندگان، پرداخت‌ها و گزارش‌ها از داخل تلگرام کنترل می‌شوند.

## ✨ چرا جذاب است؟

- چهار ربات هماهنگ برای **مدیر، کاربر، نماینده و مشتری نماینده**
- فروش و تمدید کاملاً خودکار
- پشتیبانی از چند سرور و چند پنل
- لینک هوشمند اشتراک با چند نود
- کیف پول، پرداخت و تایید خودکار پیامک بانکی
- سیستم کامل نمایندگی و ربات اختصاصی مشتری
- گزارش فروش، مانیتورینگ، بکاپ و مدیریت خطا

## 🛒 تجربه کاربر

کاربر بدون نیاز به ارتباط دستی با ادمین می‌تواند:

- اشتراک بخرد یا تمدید کند
- حجم و مدت دلخواه انتخاب کند
- تست رایگان دریافت کند
- موجودی کیف پول را شارژ و استفاده کند
- مصرف و زمان باقی‌مانده را ببیند
- لینک اشتراک، کانفیگ و کد `QR` دریافت کند
- از کد تخفیف و تخفیف حجمی استفاده کند
- دوستان خود را دعوت کند و پاداش بگیرد
- تیکت پشتیبانی ثبت کند
- هشدار پایان حجم یا زمان دریافت کند

## ⚡ فروش و تمدید خودکار

از لحظه ثبت سفارش تا تحویل سرویس، عملیات توسط ربات انجام می‌شود:

- محاسبه خودکار قیمت
- پرداخت از کیف پول یا روش‌های فعال
- ساخت سرویس روی سرور اصلی
- ساخت و همگام‌سازی روی نودها
- تحویل لینک اشتراک و `QR`
- تمدید حجم و زمان
- پشتیبانی از تمدید افزایشی یا ریست
- ثبت کامل سفارش و تراکنش

## 🤝 سیستم نمایندگی

هر نماینده پنل مستقل خودش را دارد:

- ساخت و مدیریت مشتری
- فروش و تمدید سرویس
- کیف پول نمایندگی
- قیمت فروش مستقل
- مشاهده هزینه عمده و سود
- گزارش مالی
- مدیریت پرداخت و تیکت
- پیام همگانی و مدیریت کانال
- راه‌اندازی ربات مشتری اختصاصی

## 👥 ربات مشتری نماینده

هر نماینده می‌تواند فروشگاه تلگرامی خودش را داشته باشد:

- ثبت‌نام مشتری
- خرید و تمدید
- پرداخت و ارسال رسید
- مشاهده وضعیت اشتراک
- دریافت لینک و کد `QR`
- تیکت پشتیبانی

چند ربات مشتری می‌توانند همزمان روی یک سیستم اجرا شوند.

## 🚀 نصب سریع

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

یا:

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
sudo ./install.sh install
```

## 🎛 مدیریت

```bash
sudo ./install.sh panel
sudo ./install.sh status
sudo ./install.sh restart
sudo ./install.sh logs
sudo ./install.sh update
```

تنظیمات نمونه در [`.env.example`](.env.example) قرار دارد.
