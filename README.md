# Hiddify-SellBot

ربات فروش و مدیریت اشتراک VPN برای تلگرام — با پشتیبانی از پنل‌های **Hiddify**، **Marzban** و **X-UI (3x-ui)**.

پروژه شامل ۴ ربات جداگانه است:

| ربات | نقش |
|---|---|
| **AdminBot** | پنل مدیریت کل سیستم برای ادمین |
| **UserBot** | فروشگاه خرید اشتراک برای مشتریان |
| **AgentBot** | پنل نمایندگی (Reseller) |
| **CustomerBot** | ربات اختصاصی مشتریان هر نماینده |

---

## 🛒 ربات کاربران (UserBot)

- ثبت‌نام خودکار کاربران تلگرام
- خرید از پلن‌های ثابت، دسته‌بندی پلن‌ها یا پلن پویا (حجم/زمان دلخواه)
- تمدید اشتراک با سیاست‌های قابل تنظیم حجم و زمان
- تست رایگان با حجم‌های اعشاری مثل `0.2` و `0.5` گیگ
- کیف پول، شارژ و پرداخت از موجودی
- نمایش وضعیت سرویس: نام، سرور، مصرف، حجم کل، زمان باقی‌مانده و قیمت
- دریافت کانفیگ مستقیم، لینک اشتراک، لینک base64 و QR داخلی
- سیستم تیکت پشتیبانی با ادمین
- زیرسیستم معرفی (رفرال) با پاداش خودکار
- کد تخفیف (کوپن) و کمپین هدیه
- یادآوری خودکار نزدیک شدن پایان حجم یا زمان
- اتصال سرویس موجود با UUID یا لینک کانفیگ
- دکمه‌های رنگی با ۴ طرح قابل انتخاب

## 🛠 ربات مدیریت (AdminBot)

- افزودن، ویرایش و حذف سرور و مدیریت دامنه‌ها
- مدیریت نودها و اتصال سرور فرعی به سرور اصلی
- ساخت کاربر روی پنل و نودهای مرتبط (تکی، گروهی، دستی)
- جستجوی کاربر با شناسه، نام کاربری و اطلاعات سرویس
- تغییر نام، حجم، زمان، وضعیت و حذف سرویس
- حذف گروهی کاربران منقضی‌شده
- مدیریت پلن‌ها: ثابت، دسته‌بندی، پویا، قیمت هر گیگ/هر ماه، تخفیف پلکانی و تایمر تخفیف
- مدیریت کارت‌های بانکی و روش‌های پرداخت
- تایید/رد پرداخت‌ها، کیف پول و تراکنش‌های کاربران
- مدیریت متن‌ها و ظاهر ربات کاربران
- مدیریت تیکت‌ها
- گزارش فروش، سفارش‌ها، تراکنش‌ها و وضعیت کاربران
- ساخت اینباند از روی لینک کانفیگ (`vless` / `vmess` / `hysteria2` / `trojan`)
- همگام‌سازی کاربران روی همه اینباندها
- مدیریت کامل سیستم نمایندگی: افزودن/حذف نماینده، شارژ کیف پول، قیمت عمده، آمار
- دستور `/debug` برای گزارش وضعیت ربات و `/enforce_now` برای اعمال فوری محدودیت‌ها

## 🤝 ربات نمایندگی (AgentBot)

- داشبورد آمار فروش، سود و موجودی
- مدیریت مشتریان و سرویس‌ها (ساخت، تمدید، فعال/غیرفعال، حذف)
- قیمت فروش مستقل برای هر پلن (حداقل برابر قیمت عمده)
- کیف پول نماینده و تراکنش‌ها
- ثبت ربات مشتری اختصاصی (۱ ربات به‌ازای هر نماینده)
- تنظیمات مستقل: پرداخت، فروشگاه، هدیه، اجبار به عضویت، پیام همگانی، تراکنش‌ها

## 👥 ربات مشتری نماینده (CustomerBot)

- ثبت‌نام خودکار مشتری در سیستم نماینده
- خرید از پلن‌های نماینده (هزینه عمده از کیف پول نماینده کسر می‌شود)
- مشاهده سرویس‌ها و مصرف
- دریافت کانفیگ‌ها و تمدید سرویس
- ارسال رسید و پیام پشتیبانی به نماینده
- اجرای همزمان همه ربات‌های فعال + افزودن/حذف ربات بدون ری‌استارت

## ⚙️ پنل‌ها و سرورها

- پشتیبانی همزمان از چند پنل: Hiddify، Marzban، X-UI (هر دو نوع 3x-ui و alireza)
- حالت چنداینبانده هوشمند: همه اینباندها، تک اینباند یا چند اینباند انتخابی
- جمع مصرف از همه نودها + کنترل محدودیت و قطع خودکار سرویس
- ساخت خودکار سرور روی **Hetzner** و ثبت DNS روی **Cloudflare**
- چک سلامت خودکار سرورها
- بکاپ خودکار دوره‌ای (دیتابیس، سرورها، پلن‌ها)

## 🔗 لینک اشتراک هوشمند

هر سرویس یک لینک اختصاصی می‌گیرد:

```text
https://your-domain.com/sub/<TOKEN>/all.txt
```

- تجمیع کانفیگ‌های همه سرورها و نودهای فعال
- ارسال حجم و زمان باقی‌مانده در هدر استاندارد
- ردیف وضعیت (مصرف/زمان) برای نمایش داخل اپ‌ها
- QR داخلی بدون سرویس خارجی
- حذف خودکار کانفیگ‌های تکراری و مخفی

## 💳 پرداخت‌ها

- کیف پول کاربر با شارژ و برداشت امن (ضد برداشت همزمان)
- کارت به کارت با ارسال رسید و مشخصه تصادفی تراکنش
- تایید خودکار پرداخت با وب‌هوک SMS بانکی (اپ اندروید در [SmsVerifierAndroid](SmsVerifierAndroid/README.md))
- درگاه زرین‌پال و ووچر
- پرفکت مانی و ارز دیجیتال (اختیاری)

## 📥 نصب سریع

روی سرور خام (حتی بدون git):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mojtaba-glx/Hiddify-SellBot/main/bootstrap.sh)
```

با git:

```bash
git clone https://github.com/mojtaba-glx/Hiddify-SellBot.git
cd Hiddify-SellBot
chmod +x install.sh
sudo ./install.sh install
```

نصب SSL برای لینک اشتراک (بعد از نصب):

```bash
sudo ./install.sh ssl your-domain.com admin@example.com
```

## 🎛 دستورهای مدیریت

```bash
cd ~/Hiddify-SellBot
sudo ./install.sh panel        # منوی مدیریت (پیشنهادی)
sudo ./install.sh status       # وضعیت ربات‌ها
sudo ./install.sh restart      # ری‌استارت
sudo ./install.sh logs         # لاگ زنده
sudo ./install.sh update       # آپدیت امن با بکاپ
sudo ./install.sh stop         # توقف ربات‌ها
sudo ./install.sh uninstall    # حذف کامل ربات (سورس می‌ماند)
```

اجراهای دستی:

```bash
cd ~/Hiddify-SellBot
python -m AdminBot.main     # ربات ادمین
python -m UserBot.main      # ربات کاربران
python -m AgentBot.main     # ربات نمایندگی
python -m CustomerBot.main  # ربات‌های مشتری
```

## 🔒 نکات امنیتی

- توکن ربات‌ها را از [@BotFather](https://t.me/BotFather) بگیرید؛ هر ربات توکن جداگانه

- دسترسی SSH سرور را امن نگه دارید
- قبل از تغییرات مهم از `Shared/hiddify_sellbot.db` و `.env` بکاپ بگیرید
