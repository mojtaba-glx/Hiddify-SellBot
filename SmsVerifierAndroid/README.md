# SellBot SMS Verifier

اپ اندروید ساده برای تایید هوشمند کارت‌به‌کارت در Hiddify-SellBot.

## راه‌اندازی (ساده — بدون «اپ پیش‌فرض پیامک»)

این اپ پیامک‌های بانکی را **مستقیم از صندوق پیامک** و به‌صورت **لحظه‌ای** می‌خواند؛
دیگر نیازی به «اپ پیش‌فرض پیامک» شدن یا دادن دسترسی از طریق adb نیست.

1. موقع باز کردن اپ، پاپ‌آپ مجوزها را **Allow** کن (مهم‌ترینشان «خواندن پیامک» / READ_SMS).
2. برای پایداری روی شیائومی/ردمی: اپ را در تنظیمات باتری روی **Unrestricted/بدون محدودیت** بگذار و **Autostart** را روشن کن.
3. تمام. اپ پیامک اصلی گوشی هم دست‌نخورده و عادی کار می‌کند.

### چطور کار می‌کند؟
- یک `ContentObserver` روی `content://sms` داخل سرویس پیش‌زمینه ثبت است؛ به‌محض آمدن
  پیامک جدید، صندوق اسکن و پیامک‌های بانکی پردازش می‌شوند (real-time).
- برادکست `SMS_RECEIVED` هم به‌عنوان «بوستر» سریع نگه داشته شده است.
- یک **اسکن دوره‌ای هر ۹۰ ثانیه** به‌عنوان جبران، اگر به‌خاطر محدودیت باتری/روم رویدادی
  از دست برود، پیامک‌های جاافتاده را می‌گیرد.
- همه از یک مجوز `READ_SMS` انجام می‌شود؛ اپ هرگز «پیش‌فرض پیامک» نمی‌شود و `SEND_SMS`
  هم نمی‌خواهد.

> حالت «خواندن از اعلان‌ها» فقط یک مسیر **جایگزین/اختیاری** است (برای کسانی که نخواهند
> مجوز SMS بدهند). روی بعضی گوشی‌ها (مثل شیائومی) متن اعلان به‌صورت پیش‌فرض مخفی است،
> پس این حالت همیشه مطمئن نیست و روش اصلی همان `READ_SMS` است.

> نسخه 1.7.3: رفع خطای کامپایلِ ۱.۷.۲ (استفاده از `Calendar.getInstance(ULocale)` +
> `setTimeZone` به‌جای اورلودِ ناموجود).
>
> نسخه 1.7.2: تاریخ هدر با **تقویم رسمی شمسی (ICU)** و منطقهٔ تهران نمایش داده می‌شود
> (مثلاً `1405/06/12`) و زیرش خط **«امروز <روز هفته>»** اضافه شد؛ بج «LIVE» حذف و
> ساعت/تاریخ/روز هفته در همان گوشه مرتب شد. به‌همین‌دلیل `minSdk` به ۲۴ (اندروید ۷+)
> افزایش یافت.
>
> نسخه 1.7.1: ساعت و تاریخ هدر اصلی به **تقویم شمسی و منطقهٔ تهران** (با ارقام فارسی)
> تغییر کرد و یک خط **تاریخ** زیر ساعت اضافه شد. به کارت درآمد هم **«۳۰ روز اخیر»** و
> **«۳ ماه اخیر»** افزوده شد.
>
> نسخه 1.7.0: حذف کامل حالت «اپ پیش‌فرض پیامک» (ROLE_SMS) و ماشین‌آلات آن
> (`SmsConfigService`, `RespondViaMessageService`, `WapPushReceiver`, `SmsSentReceiver`,
> مجوزهای `SEND_SMS`/`RECEIVE_MMS`/`RECEIVE_WAP_PUSH`). خواندن پیامک حالا با
> `READ_SMS` + `ContentObserver` + اسکن دوره‌ای انجام می‌شود؛ نصب بدون کابل/adb و
> بدون دستکاری گوشی. برای اندروید ۱۳+ (شیائومی/HyperOS) هم دکمهٔ «تنظیمات مجوز پیامک
> (Allow all the time)» در صفحهٔ امنیت اضافه شد تا کاربر راحت مجوز پیامک را روی
> «همیشه اجازه بده» بگذارد.
>
> نسخه 1.5.1: همگام‌سازی هوشمند اضافه شد — رکوردهای تایید‌نشده هنگام باز شدن اپ و
> به‌صورت دوره‌ای در سرویس پس‌زمینه خودکار استعلام می‌شوند؛ پس اگر پرداخت در تلگرام
> تایید شود، رکورد بدون زدن «همگام‌سازی» به «تایید شده» می‌رود. تعداد پیامک‌های
> قابل نمایش هم به ۵۰ رسید.

## کارکرد

- دریافت SMSهای جدید روی گوشی
- بررسی فقط سرشماره‌های مجاز بانک
- استخراج مبلغ، واحد پول و کد/شماره پیگیری
- فیلتر اختیاری چهار رقم آخر کارت به‌صورت جدا برای هر بانک
- ارسال نتیجه به Webhook ربات با `Secret Key`
- ثبت گزارش SMSهای ارسال‌شده، خطاخورده یا ردشده داخل خود اپ
- اجرای پایدارتر در پس‌زمینه با Foreground Service و شروع مجدد بعد از ری‌استارت گوشی

## امنیت

- اپ توکن تلگرام نمی‌گیرد و مستقیم به Telegram وصل نمی‌شود.
- همه درخواست‌ها به endpoint اختصاصی ربات ارسال می‌شود.
- هر درخواست با هدر `X-SellBot-Sms-Secret` و `X-SellBot-Event-Id` فرستاده می‌شود.
- اگر سرشماره بانک تنظیم نشده باشد، هیچ SMSای ارسال نمی‌شود.
- اپ فقط SMSهای بانکیِ سرشماره‌های تعریف‌شده را پردازش می‌کند.
- بررسی پیامک‌های قبلی فقط با دکمه دستی داخل اپ انجام می‌شود و برای جبران SMSهای دیررس کاربرد دارد.

## تنظیمات داخل اپ

1. `فعال‌سازی پردازش خودکار SMS` را روشن کنید.
2. `Webhook URL ربات` را وارد کنید. نمونه:

   ```text
   https://sell.example.com/payment/sms-webhook
   ```

3. `Secret Key اتصال` را وارد کنید.
   اگر پیام کامل ربات را اشتباهی paste کنید، اپ تلاش می‌کند URL و Secret را خودش جدا کند.
4. وارد بخش `بانک‌ها و الگوهای SMS` شوید.
5. برای هر بانک، سرشماره‌ها و یک نمونه SMS واقعی همان بانک را ثبت کنید.
6. اگر همان بانک داخل SMS چهار رقم کارت مبدا را می‌فرستد، گزینه چهار رقم کارت همان بانک را روشن کنید.
7. اگر بانک چهار رقم کارت را نمی‌فرستد، این گزینه را برای همان بانک خاموش بگذارید.
8. برای پایداری بیشتر، از بخش `امنیت` تنظیمات مصرف باتری را باز کنید و اپ را روی حالت بدون محدودیت بگذارید.

## بانک‌های تست‌شده

- `بلو`: پیامک «واریز پول» با مبلغ ریالی و موجودی حساب؛ اپ مبلغ واریزی را می‌خواند و موجودی را نادیده می‌گیرد.
- `بانک خاورمیانه`: پیامک «انتقال از اینترنت بانک از کارت 4188»؛ اپ مبلغ مثبت، شماره پیگیری و چهار رقم کارت را استخراج می‌کند.
- پیامک‌های برداشت/خرید مثل «برداشت پول» بلو یا «خرید با کارت» خاورمیانه رد می‌شوند و برای تایید پرداخت ارسال نمی‌شوند.

## تبدیل ریال/تومان

- اپ مبلغ SMS را همان‌طور که از بانک می‌خواند ارسال می‌کند.
- اگر داخل SMS کلمه `ریال` باشد، ربات مبلغ را به تومان تبدیل می‌کند.
- اگر داخل SMS کلمه `تومان` باشد، مبلغ بدون تبدیل استفاده می‌شود.
- اگر واحد پول مشخص نباشد، ربات هر دو حالت تومان و ریال را امتحان می‌کند تا پرداخت pending پیدا شود.
- زمان و تاریخ دریافت SMS توسط خود اپ در `received_at` و `device_time` ثبت و ارسال می‌شود.


## ساخت APK

با Android Studio:

1. پوشه `SmsVerifierAndroid` را باز کنید.
2. صبر کنید Gradle Sync کامل شود.
3. از منوی `Build > Build Bundle(s) / APK(s) > Build APK(s)` خروجی APK بگیرید.

با ترمینال روی سیستمی که Java و Android SDK دارد:

در ویندوز، ساده‌ترین راه:

```powershell
cd C:\Users\mojte\OneDrive\Desktop\SmsVerifierAndroid
powershell -ExecutionPolicy Bypass -File .\build-debug-apk.ps1
```

برای نصب واقعی روی گوشی، خروجی release امضاشده پیشنهاد می‌شود:

```powershell
cd C:\Users\mojte\OneDrive\Desktop\SmsVerifierAndroid
powershell -ExecutionPolicy Bypass -File .\build-release-apk.ps1
```

یا با Gradle مستقیم:

```bash
cd SmsVerifierAndroid
gradle assembleDebug
```

خروجی:

```text
app/build/outputs/apk/debug/app-debug.apk
app/build/outputs/apk/release/SellBotSmsVerifier-vX.Y.Z-release.apk
```

فایل‌های `sellbot-release.jks` و `keystore.properties` محلی و حساس هستند؛ آن‌ها را حذف نکنید و داخل GitHub نفرستید.

## پیشنهاد اتصال به ربات

برای فعال‌سازی روی سرور ربات، داخل `.env` این مقدارها را بگذارید:

```env
SMS_WEBHOOK_ENABLED=true
SMS_WEBHOOK_SECRET=یک_رمز_طولانی_و_تصادفی
SMS_WEBHOOK_MAX_PENDING_AGE_MINUTES=360
```

بعد ربات را restart کنید و در اپ همان Secret را وارد کنید.

در سمت ربات:

- دریافت `test=true` فقط برای تست اتصال
- رد کردن event تکراری با `event_id`
- تطبیق مبلغ با پرداخت‌های pending
- محدود کردن اختلاف زمان SMS با سفارش
- ثبت گزارش تایید/رد در جدول `userbot_sms_webhook_events`
